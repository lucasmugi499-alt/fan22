# Platform Admin Wiring Matrix

Status: build 31 platform admin restructure slice.

The Platform Admin is a dedicated `platform_operator` experience. Broad authority must move through trusted server APIs, capability checks, lifecycle validation, and immutable audit events. This matrix records what each visible Platform Admin surface reads and which actions are actually wired.
