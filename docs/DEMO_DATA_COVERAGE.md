# Demo Data Coverage

Investor demo data should be classified honestly.

Existing final scores may continue to power demonstration standings when the result is official. Existing events should not be inflated to imply data that was never collected.

Use these fields on match coverage reports:

- `resultCoverage`
- `rosterCoverage`
- `eventCoverage`
- `statisticCoverageLevel`
- `fantasyEligible`
- `qualityScore`
- `qualityIssues`

Current historical rugby and basketball demo events should be treated as partial unless they can reconstruct the score and reconcile player totals. Fantasy pilots should use an internally consistent fixture pack with verified rosters and complete basic scoring events.
