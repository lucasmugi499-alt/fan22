# Rule Packs

GoalPlace256 separates rule packs by concern:

- Sport definition: vocabulary and legal scoring events.
- Competition rule pack: standings, bonuses, deductions and tie-breakers.
- Data collection profile: required, optional and unsupported fields.
- Statistic definition pack: how official events become statistics.
- Fantasy scoring profile: how official statistics become Fantasy Points.
- Engagement point profile: how platform participation becomes Community Points.
- Display profile: labels and UI presentation.

Active packs are immutable. A change requires a new version, validation, simulation, approval and scheduled activation.

Rule packs must not store executable JavaScript. Use constrained operators such as count, sum, comparisons, conditional awards and threshold bands.
